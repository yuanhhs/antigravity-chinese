# 项目介绍

Antigravity 简体中文汉化项目为 Antigravity 桌面端及 VS Code 中的 Antigravity 扩展提供中文界面。它适合希望用中文操作界面的用户，也为愿意补充译文的贡献者提供词库和校验工具。

项目覆盖桌面端主界面、设置、系统菜单和托盘菜单；扩展部分覆盖命令、设置说明和部分侧栏界面。支持 Windows 和 macOS。具体汉化范围可能随 Antigravity 或扩展更新而变化。

## 下载与安装

从 [Releases 页面](https://github.com/yuanhhs/antigravity-chinese/releases) 下载适配当前 Antigravity 版本的汉化包，解压后按仓库首页的[安装说明](../README.md#安装)运行脚本。安装时会备份原始文件，卸载可通过备份还原。Antigravity 或扩展升级后，通常需要重新安装对应的汉化包。

## 翻译维护

界面词条位于 `dicts_src/`，原生菜单等译文位于 `locales/zh-CN.json`。欢迎参考[翻译维护约定](translation-style.md)补充译文，并在提交前运行词条校验与测试。命令及提取步骤见仓库首页的[补充翻译](../README.md#补充翻译)。
