# Antigravity 2.18.1 汉化更新

适配 Antigravity 桌面版 2.18.1。新增词库也供 VS Code 扩展汉化使用。

- 新增 104 条词库记录，覆盖内置浏览器、权限预设、插件认证、对话遥测、上下文预算、计费选项及更新提示；其中品牌、`plan` 命令和内置浏览器标识共 3 条保持英文。
- 补充原生菜单“连接到 WSL”和“在本地重新打开”。
- 预算提示中的英文单复数词和助词按当前模板翻译，保留动态参数与条件求值；未知分支会拒绝替换并记录错误。
- 重新汉化时核对官方备份版本。官方升级后使用新版本文件建立备份并保留旧备份，避免旧备份覆盖新版。已汉化但缺少同版本官方备份时会停止安装。
- `--no-kill` 模式不会额外启动客户端；安装完成后手动重启以生效。

## 验证

已使用本机 2.18.1 官方前端源码验证：源码扫描待翻项为 0，翻译后的完整 JavaScript 通过语法与参数校验，16 段渲染库和工具摘要保护区继续生效。

已通过自动化测试及 Windows 官方资源副本的安装与备份验证。源码扫描不包含所有服务端动态文案，不代表所有运行时界面均已人工核对；macOS 未进行实机验证。

## 安装

解压 `2.18.1.zip`，运行平台对应的双击脚本并选择安装桌面版汉化。安装会关闭正在运行的 Antigravity，请先保存工作。升级过 VS Code 扩展的用户可选择安装插件汉化，并在 VS Code 中执行 `Developer: Reload Window`。
