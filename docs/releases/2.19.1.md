# Antigravity 2.19.1 汉化更新

适配 Antigravity 桌面版 2.19.1，提供按版本号命名的 Windows EXE 和 macOS App。新增词库也供 VS Code 扩展汉化使用。

## 更新内容

- 新增 22 条词库记录，其中 18 条补充中文译文，3 个内部组件名及与现有档位一致的 `Max` 保留英文。
- 补齐图表缩放与 SVG 下载、PDF 导出、搜索提示、目标面板、分叉警告、通知和语言服务器发布通道等文案。
- Windows 提供单文件 `v2.19.1.exe`，内嵌安装脚本和最新词库。
- macOS 提供 `v2.19.1.app`，支持 macOS 12 及以上的 Apple Silicon 和 Intel Mac。双击后打开与 Windows 版相同的操作菜单。

## 下载与安装

| 系统 | 下载文件 | 使用方式 |
| --- | --- | --- |
| Windows | `v2.19.1.exe` | 双击运行，选择需要的安装或卸载操作 |
| macOS | `v2.19.1.app.zip` | 解压后双击 `v2.19.1.app`，选择需要的操作 |

运行前请安装 Node.js LTS（含 npm）；首次安装汉化需要联网获取打包工具。安装桌面版汉化会关闭 Antigravity，请先保存工作。macOS 安装时会请求管理员密码，默认目标为 `/Applications/Antigravity.app`。

安装完成后重新打开 Antigravity；VS Code 插件汉化完成后，执行 `Developer: Reload Window`。工具会备份官方文件，卸载时可还原。校验值见附件 `SHA256SUMS.txt`。

## 验证情况

- 2.19.1 前端源码扫描待翻项为 0；词库共 4043 条界面词条、41 条原生界面词条。
- 翻译后完整 JavaScript 通过语法和参数校验，16 段渲染库与工具摘要保护区继续生效；25 项自动化测试通过。
- 已在本机 Windows 安装并核对同版本官方备份；EXE 启动、解压及内嵌文件完整性验证通过。
- macOS 两种架构的 Mach-O 启动器、App 结构、可执行权限、脚本语法及内嵌词库已完成校验。App 未经 Apple Developer ID 签名或公证，尚未进行 macOS 实机安装验证。

源码扫描不覆盖全部服务端动态文案，待翻项为 0 不代表所有运行时界面都已人工核对。
