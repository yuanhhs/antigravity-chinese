# Antigravity 2.21.1 兼容说明

官方于 2026-10-08 推送了 Antigravity 2.21.1 更新。

经与官方安装包及语言服务对比：
- 2.21.1 的前端核心文件（`main.js`）与 2.21.0 完全一致（SHA-256 逐字节相同）。
- 官方仅对底层依赖和版本号进行了小幅更新，界面文案无任何变动。
- **[v2.21.0 汉化包](https://github.com/yuanhhs/antigravity-chinese/releases/tag/v2.21.0) 完全兼容 2.21.1**，无需更新词库。

### 使用方式

- **已安装汉化的用户**：官方更新后如果界面恢复为英文，只需重新运行本地已有的汉化脚本（双击运行汉化工具或执行 `node localization_engine.js`）即可恢复中文。
- **新用户**：请直接前往 [v2.21.0 Release 页面](https://github.com/yuanhhs/antigravity-chinese/releases/tag/v2.21.0) 下载对应的 Windows 单文件版或 macOS App 版汉化工具。
