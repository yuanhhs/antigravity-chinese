# Antigravity 2.21.0 汉化更新

适配 Antigravity 桌面版 2.21.0，提供按版本号命名的 Windows EXE 和 macOS App。新增词库也供 VS Code 扩展汉化使用。

## 更新内容

- 新增 133 条词库记录，其中 125 条补充中文译文，8 项内部技术标识（`__AGY_BROWSER_SELECTION__`、`CRON_TZ`、`BoN`、`OAuth`、`Extra` 等）保持英文。
- 重点覆盖新引入的功能界面：
  - **Chief of Staff**：常驻幕僚长对话管理、常驻麦克风监听、快捷对讲与语音状态提示。
  - **自动化 (Automations)**：新建与编辑自动化、事件触发器与时间触发器、Cron 表达式支持。
  - **模型评测 (Harness / BoN)**：harness 选择器、对照组运行策略、分支配对。
  - **插件与账号体系**：多账号连接与重新验证、凭据管理、资源与文件夹选择。
  - **界面细节与提示**：上下文感知访问拦截、动态参数与复数模板插值。
- Windows 提供单文件 `v2.21.0.exe`（0.24 MB），内嵌极简原生启动器与全量词库。
- macOS 提供通用架构 `v2.21.0.app` 及 `v2.21.0.app.zip`，支持 Apple Silicon 和 Intel Mac。

## 下载与安装

| 系统 | 下载文件 | 使用方式 |
| --- | --- | --- |
| Windows | `v2.21.0.exe` | 双击运行，选择需要的安装或卸载操作 |
| macOS | `v2.21.0.app.zip` | 解压后双击 `v2.21.0.app`，选择需要的操作 |

运行前请安装 Node.js LTS（含 npm）；首次安装汉化需要联网获取打包工具。安装桌面版汉化会关闭 Antigravity，请先保存工作。macOS 安装时会请求管理员密码，默认目标为 `/Applications/Antigravity.app`。

安装完成后重新打开 Antigravity；VS Code 插件汉化完成后，执行 `Developer: Reload Window`。工具会备份官方文件，卸载时可还原。校验值见附件 `release/SHA256SUMS.txt`。

- 2.21.0 前端源码扫描待翻项为 0；词库共 4,176 条界面词条、41 条原生界面词条。

- Windows 单文件 EXE 和 macOS 通用架构 App 均已构建完成并生成 SHA-256 校验哈希。
